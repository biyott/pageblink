## 맥락

- [ADR 014](014-model-catalog-and-rotation.md)는 기본 모델을 `google/gemma-4-26b-a4b-it:free`로, 로테이션을 무료 모델끼리로 정했다.
- 2026-10-16 실측(research 033)에서 기본 모델이 **상류 429로 계속 실패**했고, 추론 모델은 **본문 전에 오래 무응답**이었다. 이력 길이는 지연의 변수가 아니었다.

| 모델 | 실측 (research 033, 표본 작음) |
|---|---|
| gemma-4-26b | 6/6회 429, 35분 동안 풀리지 않음. 속도는 측정 불가 |
| nemotron-3.5-lightning | 5회 모두 100초 무응답 |
| nemotron-3-super | 추론을 켜면 본문 0/4(600토큰을 전부 추론에 씀), **끄면 첫 본문 0.5초** |
| nemotron-3-ultra | 끄면 첫 본문 0.8초(기본 호출은 503 섞임) |
| nemotron-3-nano-omni | 끄면 빠르나(0.4~0.5초) 불안정(502·100초 무응답 다수) |
| gemini-3.1-flash-lite (유료) | 첫 글자 약 1초, 호출당 약 0.1~0.2센트 |
| gemini-3.8-flash (유료) | 추론을 끌 수 없어 첫 본문 약 5초 |

## 결정

- **기본 모델**: `nvidia/nemotron-3-super-120b-a12b:free`.
- **추론 끄기**: super·ultra는 요청에 `reasoning {effort: none}`, nano는 `reasoning {enabled: false}`. gemini는 추론 필드를 보내지 않는다(3.8-flash는 끌 수 없고, 3.1-flash-lite는 보내지 않기로 함).
- **자동 로테이션 순서**: super → ultra →(무료 2회 시도 후) `google/gemini-3.1-flash-lite` → `google/gemini-3.8-flash`.
- **수동 선택 전용("unstable")**: gemma·lightning·nano. 자동 로테이션에서 뺀다. 사용자가 고르면 첫 시도로는 쓰이고 실패하면 로테이션이 이어진다.
- **첫 본문 글자 10초 타임아웃**: 기준은 첫 `content` 글자다(추론 델타는 0.4~0.9초에 와서 무응답을 못 거른다).
- **유료 폴백 일일 상한 300**: 메모리 카운터.
- **환경값**: `LLM_ROTATION=all`(자동 유료 폴백을 켜는 값. **코드 기본값은 `free`**이며 운영 설정값은 확인 필요 ⚠️), `LLM_FREE_ATTEMPTS`(기본 2), `LLM_FIRST_TOKEN_TIMEOUT_SECONDS`(기본 10), `LLM_PAID_DAILY_CAP`(기본 300, 0이면 폴백 끔). 무료 시도·유료 폴백·상한은 `all`일 때만 동작하고, `off`에서는 타임아웃도 없다.
- **모두 실패했을 때**: "답변 모델이 일시적으로 바쁩니다. 잠시 후 다시 시도해 주세요." 문구를 보여준다.
- **인용 마커 인식과 보정**
  - 모델 출력의 `[n]`, `【n】`, `［n］`을 모두 인식하고, 프롬프트는 반각 `[n]`을 쓰도록 요청한다.
  - 모델이 마커를 0개 낸 답은 서버가 근거와 맞춰 **보정 인용**을 붙인다: 정방향 일치, 짧은 답변은 역방향 일치. `Citation.inferred=true`, 최대 3개, 여러 근거에 나오는 모호한 구절은 무시한다.
  - 진단: 마커 없는 답변이 약 35%였다 (`af4259f` 커밋 메시지).

## 대안과 기각 이유

| 대안 | 기각 이유 |
|---|---|
| 014 유지(gemma 기본) | 실측에서 계속 429. 기본 모델이 항상 실패하면 로테이션이 매 요청마다 헛도는 비용만 낸다 |
| 추론을 켠 채로 사용 | super는 본문 0/4, ultra·nano는 첫 본문 10~40초 |
| 유료 모델 기본 | 비용이 매 호출 발생. 무료로 충분히 빠른 경로(super 추론 끔)가 있다 |
| gemini에도 `effort: none` 전송 | 3.8-flash는 거부(필수 추론), 3.1-flash-lite는 이미 약 1초라 이득 없음 |
| 마커가 없는 답을 그대로 둠 | 출처 없는 답이 약 35%. 단 보정 인용은 모델이 낸 것과 구분해 표시한다(점선 "관련 출처(자동 연결)") |

## 결과 (좋아지는 점 · 감수할 점 · 재검토 조건)

**좋아지는 점**

- 무료 기본 경로의 첫 본문이 약 0.5초로 줄고, 무료가 막혀도 유료 폴백으로 답이 나온다.

**감수할 점**

- 표본이 작고(조건당 0~2회) 금요일 낮 한 번의 측정이다. 추론을 끈 모델의 **답변 품질은 평가하지 않았다**.
- 유료 폴백 카운터는 **프로세스 단위 메모리**라 인스턴스가 여럿이면 실제 합계는 300을 넘을 수 있고, 재시작하면 0으로 돌아간다.
- 무료 모델은 입력이 수집될 수 있다(ADR 014 그대로). 유료 폴백은 `data_collection: deny`를 유지한다.
- 보정 인용은 어휘 겹침 휴리스틱이라 틀릴 수 있고, 서술형 짧은 답변은 아직 커버가 약하다.

**재검토 조건**

- gemma 한도가 풀리면 같은 스크립트로 속도를 다시 잰다.
- 추론을 끈 무료 모델의 인용 정확도·답변 품질을 평가한다.
- 유료 폴백 비용이 문제가 되면 카운터를 DB·공유 저장소로 옮기거나 상한을 낮춘다.
