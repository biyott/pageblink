# 021 · 줄 단위 청크 + 검색용/맥락용 2단 구조 + 부팅 후 재색인

| 상태 | 결정일 | 근거 |
|---|---|---|
| 채택 | 2026-10-16 | [research 027](../research/027-citation-span-highlight.md) · [research 029](../research/029-line-level-chunking.md) · [devlog 011](../devlog/011-chunk-v2-two-tier-u2-locale-demo.md) |

## 맥락

- 노트는 대개 짧아서 **노트 1개 = 청크 1개**였고, 출처(⚡)를 누르면 노트 전체가 하이라이트됐다 ✅ (research 027).
- 그때의 청크 텍스트는 노트 본문의 **부분 문자열이 아니었다** ✅ (research 029). 그래서 인용 구간을 본문에서 정확히 찾을 수 없었다.
- 청크 규칙을 바꾸면 기존 문서도 다시 색인해야 하는데, 전체 재색인 경로가 코드에 없었다.

## 결정

**청크 규칙**

- **노트**: 줄/블록 단위 청크. 6자 미만 조각은 이웃과 병합, 300자를 넘는 줄만 분할, 겹침 없음, 마크다운 기호 보존. 불변식은 `chunk.text == body.substring(start, end)`.
- **제목 경로**: 임베딩 입력에만 붙인다(저장·인용 텍스트에는 붙이지 않음).
- **PDF**: 문장 묶음(목표 120자·최대 300자, 큰 문서는 목표 300). 페이지 경계는 유지한다.

**2단 구조**

- 검색·인용은 작은 단위(위 청크)로 한다. LLM에는 큰 단위를 `EVIDENCE`/`CONTEXT`로 나눠 준다.
- 큰 단위는 **저장하지 않고 읽을 때 계산**한다(노트 = 제목 구간, PDF = ±2 창).
- 상위 k를 8 → 16, 컨텍스트를 6,000자로 한다.
- `Citation.quoteStart`를 추가한다(비테이블 모델이라 DB 마이그레이션 없음).

**재색인**

- 구버전 표식은 `Document.embeddingModel = '<모델>#c2'`. 플래그는 `CHUNKER_VERSION`.
- 부팅 후 백그라운드 잡, 플래그 `REINDEX_ON_BOOT`. 문서 사이 1.5초, 429 백오프 30→60→120초, 연속 5회 실패 시 중단.
- 문서마다 **임베딩을 먼저** 만들고, 한 트랜잭션에서 버전을 재확인한 뒤 청크를 교체한다(조건부 교체). 실패하면 옛 청크를 그대로 둔다.

## 대안과 기각 이유

| 대안 | 판단 |
|---|---|
| A. 청크 축소 | **채택(줄 단위로 축소).** research 027은 300~400자로 줄이는 것만으로는 짧은 노트에 효과가 없다고 봤다. 줄/블록 단위로 줄이면 짧은 노트도 여러 청크가 되고, 위의 불변식·`quoteStart`와 함께 쓰면 한 줄이 하이라이트된다 |
| B1. LLM이 근거 문장을 출력 | CTO가 폐기. Ask 출력 형식이 바뀐다 |
| B2. 질문 시 문장 선택 | 보류 |
| 큰 단위를 따로 임베딩 | 보류. 품질이 부족하면 전환 |
| 큰 단위·오프셋을 컬럼에 저장 | 보류. 품질이 부족하면 전환 |
| 맥락 접두를 청크에 저장 | 기각. 인용에 접두가 섞인다 |

## 결과 (좋아지는 점 · 감수할 점 · 재검토 조건)

**좋아지는 점**

- 9차 배포 후 운영 재색인 5개 문서 13초, 실패 0 ✅ (`ok=5 skipped=0 failed=0`).
- 새로 저장한 노트는 줄 단위로 색인되고, 인용이 한 줄을 가리킨다 ✅.
- 재색인 술어(`status='ready' AND embeddingModel <> 현재 태그`)가 [ADR 002](002-embedding-embeddinggemma-768.md)의 모델 전환과 같다. 임베딩 공급자를 바꿔도 같은 경로로 다시 색인된다.
- DB 스키마 변경 없음.

**감수할 점**

- 하드 랩 문단은 줄 단위로 갈린다(research 029 §2.4).
- 상위 k 16, 컨텍스트 상한 6,000자. 질문당 토큰·지연 변화는 ⚠️ 미측정.
- 운영의 대량 문서 재색인 속도·임베딩 한도는 ⚠️ 미확인.

**재검토 조건**

- 검색 품질이 부족하면 → 큰 단위 임베딩 또는 오프셋 컬럼 저장으로 전환(새 ADR, 이 문서와 상호 링크).
- 임베딩 모델을 바꾸면 → 같은 재색인 경로를 쓴다.
