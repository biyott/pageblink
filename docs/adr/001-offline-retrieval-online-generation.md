# 001 · v1 온디바이스 범위: 오프라인 검색 + 온라인 생성

| 상태 | 결정일 | 근거 |
|---|---|---|
| 채택 | 2026-10-14 | [research 002](../research/002-flutter-ondevice-rag-stack.md) |

## 맥락
Android 우선으로 오프라인 RAG를 지원하고 싶다. 임베딩 모델은 ~180MB지만 생성 모델은 2.4~6.5GB이고 RAM 요구량·한국어 품질이 불확실하다.

## 결정
- v1(Android): **검색(임베딩·벡터·FTS)은 기기에서**, **답변 생성은 서버 경유 LLM**
- 오프라인일 때는 **Evidence 모드**(근거 구절 + 페이지만 표시)
- 오프라인 생성(Gemma E2B 다운로드 / Gemini Nano / Apple FM)은 고사양 기기 **옵션**
- Web은 온라인 전용

## 대안과 기각 이유
- 완전 오프라인 기본값: 다운로드 크기, 저사양 크래시, 한국어 품질 리스크
- 온라인 전용: 제품 차별점(기기 전용 문서)을 잃음

## 결과
- 👍 v1 리스크 최소화, 오프라인에서도 검색 앱으로서 가치 유지
- 👎 오프라인 답변 품질은 Phase 2까지 제한
- 🔁 재검토: 온디바이스 한국어 생성 품질이 검증되면
