## 맥락
[ADR 013](013-llm-via-openrouter.md)은 기본 모델을 `anthropic/claude-haiku-5.5`로, 모든 요청에 `data_collection: deny`를 걸고, 무료(`:free`) 모델은 비권장으로 정했다. 해커톤 데모는 비용을 낮추는 쪽이 유리하고(무료 모델), OpenRouter 무료 모델은 혼잡·한도로 실패할 수 있다.

## 결정
- 서버가 **모델 카탈로그**(`LlmCatalog`, 7개)를 갖고 `ModelEndpoint.list` / `defaultModel`로 앱에 내려준다. 앱은 모델 선택기와 "답한 모델" 배지를 보여준다.
- 기본 모델은 `google/gemma-4-26b-a4b-it:free`. 설정값 `llmModel`로 바꿀 수 있다.
- `RotatingLlmProvider`: 첫 글자가 나오기 **전에** 재시도 가능한 오류(402/404/408/429/5xx)가 나면 다음 모델로 넘어간다. 글자가 나온 뒤의 오류는 숨기지 않고 그대로 낸다.
- 설정값 `llmRotation`: `free`(기본, 무료 모델끼리) · `all`(유료까지) · `off`(선택한 모델만).
- **무료 모델에는 `data_collection: deny`를 보내지 않는다** (무료 모델은 데이터 수집 제공자에서만 서비스되는 경우가 많다는 코드 주석 기준). 유료 모델은 계속 deny.

## 대안과 기각 이유
- 013 유지(Haiku 기본, deny 항상): 데모 비용 발생
- 로테이션 없이 단일 무료 모델: 혼잡·429 때 답변 실패가 그대로 사용자에게 노출

## 결과
- 👍 비용 0으로 데모 가능, 모델 하나가 막혀도 답변 유지, 사용자가 모델 선택
- 👎 무료 모델 사용 시 프롬프트(문서 발췌 포함)가 제공자에게 수집될 수 있음 ⚠️ → **데모는 공개 문서로만**, 민감 문서는 Cloak(기기 전용, 예정) 또는 유료 모델 + deny
- 👎 OpenRouter 무료 한도는 **계정 단위**(일 50회, 크레딧 $10 이상 구매 후 일 1,000회, 분당 20회)라 로테이션은 혼잡에는 도움이 되지만 일일 한도는 못 넘는다
- 🔁 재검토: 인용 품질이 무료 모델에서 부족하면 유료 모델 기본으로 복귀, Gemini 직접 호출 구현 시 한도 분산
