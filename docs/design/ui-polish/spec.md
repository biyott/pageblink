## 2. 진단 요약 (화면별)

**공통 (가장 큰 원인)**
- ✅ **한글이 어절 중간에서 줄바꿈된다.** "출/처가", "질문하/면", "시작/하기", "사항/은?" (`current-hangul-linebreak.png`). Flutter에는 CSS `word-break: keep-all`이 없다. 작은 한글이 "어설프다"는 인상의 1순위이고, 폰트를 바꿔도 안 풀린다.
- ✅ **작은 한글은 w500을 요청해도 w400 면이 나온다**(HEAD 번들 400/600뿐; `current-hangul-weights.png`에서 11/12/13px의 w400과 w500이 동일). 라틴 Inter는 500이 실제로 달라서 같은 칩 안에서 `PDFs 2`는 중간 굵기, `노트`는 얇게 보인다. (Pretendard 작업이 해소 중.)
- ✅ **M3 기본 자간이 한글에도 붙는다.** theme.dart가 자간을 덮어쓰지 않아 `bodySmall` +0.4, `labelSmall/Medium` +0.5, `bodyLarge` +0.5, `bodyMedium` +0.25(Flutter `typography.dart` 값). 12px 한글에 +3%대 자간이 들어가 글자가 흩어진다. 섹션 라벨 `최근`/`계층`은 11px w600 + 0.8까지 더해진다.
- ✅ **보조 텍스트 대비는 숫자로는 통과하지만 11~12px 한글에는 얇다.** `inkMuted #6B6358`은 유리 위 5.5:1, 노트 파스텔 위 4.6~5.2:1(AA 통과). 문제는 대비율이 아니라 **획 두께 × 크기**다. 다크는 숫자도 모자란다(버터 노트 3.88, `glassStrong` 4.25, 민트 4.44 → AA 4.5 미달). 출처 행 쪽은 `subInkFor`(ink 75%)로 우회했다.
- ✅ **컨트롤 모양이 섞여 있다.** "새 노트"는 r14 사각, 바로 옆 "PDF 올리기"는 pill(M3 기본 OutlinedButton). 다이얼로그·바텀시트·팝업 메뉴·스낵바는 테마가 없어 M3 기본 흰 면이다(⚠️ 코드 기준, 캡처 안 함).
- ✅ **정적 문자열의 ⚡는 문자다.** "모든 답변은 ⚡ 출처로…", 면책 문구, 폰 AppBar 제목 `⚡ PageBlink`. 캡처에서는 두부 글리프(테스트 환경에 이모지 폰트가 없음)지만 실제 기기에서는 OS 컬러 이모지로 폴백해 보라 UI 안에서 노란 번개가 된다(⚠️). 데스크톱 사이드바는 별 아이콘인데 폰 헤더는 이모지라 **브랜드 마크가 두 가지**다.

**보드(노트)**
- ✅ 카드가 정보를 너무 많이 말한다: 모든 개인 노트에 `내 클라우드` 칩, 메타 `노트 · 2분 전`(폰에서 `노트 · 2…`로 잘림), 미리보기가 반쯤 잘린 줄로 푸터 칩과 겹침. PDF 카드는 큰 빈 흰 칸. 실패 카드 `_FailedBlock`은 280×250에서 **3px overflow**(캡처에 빗금).
- ✅ 외곽선 ink 10%가 파스텔 위에서 어두운 테두리로 보여 카드가 "윤곽선 있는 상자" 같다. 노트 그림자는 약하다.
- ✅ 경고 배너는 전폭 사각 노란 띠 + **원시 에러 문구**(`embedding timeout`)가 둘째 줄에 그대로 나온다. 위 `최근` 라벨과 간격이 0이다.
- ✅ 폰: 필터 칩이 두 줄로 줄바꿈, FAB 두 개(작은 PDF + 확장 새 노트)가 카드를 가린다. 로그아웃이 설정 바로 옆 아이콘이다.

**질문(Ask)**
- ✅ 빈 상태: 헤더 아이콘과 중앙 큰 아이콘이 같은 말풍선(?)으로 중복, 제안 카드 8장이 똑같은 흰 사각으로 화면 절반. 컴포저가 3행(범위 / 입력+전송 / 모델)이고 빈 입력의 전송 버튼이 베이지 회색 원이라 "고장난 버튼" 같다.
- ✅ 답변 본문이 14/1.45로 질문 말풍선(15)보다 작다(AB v2 스펙은 15/1.55). 긴 답변에서 질문 말풍선이 스크롤 위로 밀려 AppBar 아래에 잘려 보인다(폰, `current-phone-ask-dark.png`).

**좁은 데스크톱 / 셸**
- ✅ 1024에서 중앙 308px = 1024−48−240−24−24−380. 카드 2열이 146px, 메타 `노…`, 제목 말줄임, 배너 5줄, 검색창이 아이콘 하나. 1100에서도 384px. 1280에서야 564px.
- ✅ 사이드바: 태그라인 2줄(어절 중간 줄바꿈), `Shared Vision` 부제가 프로젝트 이름을 쉼표로 이어 말줄임, 카운트 `1`이 제목 줄에 떠 있음(베이스라인 어긋남).

**프로젝트 / 설정 / 편집기 크롬**
- ✅ 프로젝트: 제목·설명·카드 없이 맨 `ListTile` 두 줄이 빈 유리 위에 떠 있다. 빈 목록은 글자 한 줄. 초대 아이콘만 있고 멤버 수·역할 표시가 없다.
- ✅ 설정: 라디오 3개 + 구분선 + 로그아웃. 그룹 카드·헤더 위계 없음, 중앙 패널의 95%가 빈 면.
- ✅ 편집기 크롬(`PaneHeader` `← 노트 / 제목`, 라이브|소스 토글)은 양호. 본문·툴바는 research 018/024 소관이라 다루지 않는다.

**다크**
- ✅ 노트 5색이 어둡고 채도가 높아 "진흙색"이다(올리브, 갈색, 남색). PDF `#2A2620`은 라벤더 배경 위에서 갈색 회색으로 떠서 노트와 한 무리로 안 읽힌다. `glass` 8% / `glassStrong` 12%는 차이가 작아 컴포저와 패널이 한 면처럼 붙는다.

## 3. 타입 스케일 (한 장)

현재 값은 theme.dart + 각 화면 코드 + M3 기본값(✅ `typography.dart`)으로 채웠다. "제안"은 한글 우선, 라틴은 같은 크기·굵기. 폰트 파일은 **Pretendard 400/500/600 번들**(진행 중 작업) 전제이고 700은 만들지 않는다(600으로 귀결; `CiteMarker` 12/700 포함). **번들 비용**: 500 면 1개 = Pretendard KS X 1001 서브셋 약 346KB(작업 트리의 `Pretendard-500-subset.otf`), Noto Sans KR 서브셋으로 만들면 약 470KB. 700은 불필요(+0).

### 5.3 상태 (호버·눌림·포커스·비활성)

> 2026-10-16 갱신(구현 14차). 포커스 링을 `accent`에서 `ink`로 바꿨다: CTO 위임 결정. 이유는 ① 다크에서 `accent` 링이 인용 pulse 위에서 대비 **2.49:1로 미달**하고 ② 보라는 인용 전용인데 포커스에도 쓰면 인용 레일과 **혼동**되기 때문이다 (interaction-states/spec.md §8 결정 1).

| 상태 | 카드 | 칩/버튼 | 내비 항목 |
|---|---|---|---|
| 호버(데스크톱 포인터 전용) | 그림자 `ink 10%` blur 16 y6 (translate 없음, v2 §2.1) | 투명·파스텔·유리 면: `ink` **6%**(다크는 흰색 6%). 보라 채움 버튼: 검정 8% | `ink` 6% 배경 |
| 눌림 | scale 0.985, 80ms | `ink` **12%**(다크는 흰색 12%). 보라 채움 버튼: 검정 14% | `ink` 12% 배경 |
| 키보드 포커스 | **2px `ink` 링, 2px 바깥 간격, 키보드 전용, 전환 0ms** | 동일 | 동일 |
| 비활성 | 글자·아이콘 `ink` **38%**, 채움 면 **8%** (전체 `Opacity` 55%는 쓰지 않음) | 동일 | 동일 |

- **포커스 링**: 색은 `ink`(라이트 `#1F1B16` / 다크 `#F2EDE3`)이라 컨트롤 면 색과 무관하다. 키보드로 포커스가 있는 동안만 보이고(`FocusHighlightMode.traditional`), 마우스 클릭에는 나타나지 않는다(텍스트 입력은 예외). 전환 없이 즉시 나타난다. 고대비 설정에서는 3px. 입력창의 포커스 테두리도 같은 `ink` 2px다 ✅ (`theme.dart`).
- **호버·눌림 틴트 전환**은 120ms이고 `disableAnimations`이면 즉시다 ✅ (`pb_interactive.dart`).
- **터치 영역**: 모바일·태블릿(폭 < 1024)은 44, 데스크톱(폭 ≥ 1024)은 36. 시각 크기가 더 작아도 히트 영역은 투명하게 늘리고 링은 시각 크기 기준으로 그린다 ✅ (`pb_interactive.dart`의 `pbTarget`). 상태 설계 단계에서는 "> 1024"로 적었으나 코드는 `>= 1024`다.
- **`controlEdge`(신규 토큰)**: 폼 입력 필드(로그인·링크·검색)와 선택 전 노트 색 견본의 **경계선**. `ink` 50%로 필드 면 대비 3:1 이상(WCAG 1.4.11). 그 밖의 헤어라인은 그대로 둔다 ✅ (`theme.dart`).
- 컴포넌트별 상세(칩·pill·행·카드·메뉴 등)는 [interaction-states/spec.md](../interaction-states/spec.md) §4~§5를 따른다.

## 11. 하지 말 것

- **폰트 패밀리를 또 바꾸지 않는다.** 진행 중인 Pretendard 작업이 끝나기 전에 UP-02를 시작하면 `theme.dart`가 충돌한다. 굵기는 400/500/600만 쓴다(700 번들 불필요 → 파일 +350KB 절약).
- **글자 크기만 키우는 해법**("전체를 한 단계 키우자")은 쓰지 않는다. 원인은 줄바꿈·자간·굵기·색이다. 키우면 카드/사이드바 밀도가 더 나빠진다.
- **모든 텍스트에 U+2060을 넣지 않는다.** 편집기 입력창·답변 마크다운·복사 대상은 제외한다(복사 시 보이지 않는 문자, 검색/일치 깨짐).
- **블러를 늘리지 않는다.** 배경이 모서리 글로우뿐이라 블러는 보이지 않고 중첩 `BackdropFilter`는 웹에서 비싸다.
- **탭/화면 전환에 슬라이드·큰 스프링을 넣지 않는다.** 깜빡이는 출처 효과(ask-sources)와 경쟁하고 보드 목록 재생성 때 멀미를 만든다.
- **보라를 더 쓰지 않는다**(채움 면은 화면당 `새 노트` 1곳 + 사이드바 활성). 환영 카드·제안 카드는 보라 테두리/타일이 아니라 노트 파스텔·`accentContainer`로.
- **노트 파스텔 5색과 PDF 흰 종이 체계를 바꾸지 않는다**(출처 행이 같은 규칙을 쓴다). 다크 값만 조정한다.
- **별(V1b)·번개를 새로운 마스코트나 일러스트로 키우지 않는다.** 앱 아이콘과 같은 형태 + 번개 알약 한 쌍까지만.
- **AB v2의 사이드바 활성 pill을 임의로 낮추지 않는다**(UP-22는 클라이언트 확인 후).
- **카드 그리드에 외부 masonry 패키지를 바로 들이지 않는다.** 3단계 높이 근사로 먼저 확인한다.

## 12. 확인하지 못한 것 (⚠️)

- 라틴은 Inter를 Raycast 앱 번들의 OTF(Regular/Medium/SemiBold/Bold, 이름별 단일 파일)로, Fraunces는 **Georgia Bold 대체**로 렌더했다. 제목의 라틴 글자 모양과 폭은 실제와 다르다. 한글(Noto Sans KR 400/600, Noto Serif KR 600)과 Lucide 아이콘은 앱 번들 그대로다.
- 캡처에서 ⚡ 문자는 두부 글리프(`▌`)다(이모지 폰트 없음). 실제 기기에서는 OS 이모지다.
- 폰 FAB와 프로젝트 `새 프로젝트` 버튼 둘레의 굵은 검은 링은 테스트 환경의 키보드 포커스 하이라이트 흔적으로 보이며 실제 앱 문제로 단정하지 않았다.
- 태블릿 600–1023, 다이얼로그·바텀시트·팝업 메뉴·스낵바, 스켈레톤/오류 상태는 캡처하지 않았다(코드 기준 진단).
- 웹(CanvasKit)에서 U+2060이 줄바꿈을 막는지, 한글 w500이 번들 교체 후 의도대로 나오는지는 실기 확인 전이다.
- 프로젝트 화면은 `client.auth.authInfo`가 null이라 소유자 전용 ⋯ 메뉴를 렌더하지 못했다.
- 답변 캡처의 `⚡n` 알약은 가짜 토큰을 서버와 같은 `[n]` 문법으로 넣어 실제 `CiteMarker`가 그려진 것이다(처음에 `⚡1` 문자로 넣어 두부 글리프가 나왔던 것을 고쳐 다시 캡처했다).
- 캡처는 다른 에이전트의 미커밋 작업(Pretendard, ask_sources) **이전**의 HEAD다. 출처 행·`⚡n` 알약의 현재 작업본 모습은 반영되지 않았다.
