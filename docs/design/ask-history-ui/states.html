Ask 대화 선택 UI 시안

헤더에 [최근 대화 ▾] + [새 대화]를 두고, 입력창 위의 대화 바를 없앤다. 색은 theme.dart Pb 토큰 hex(라이트·다크 같은 파일, ?t=dark)와 상호작용 기준안(링 2px ink, hover 6%, pressed 12%) 값이다. 데스크톱 프레임은 실제 Ask 열 폭 380(main.dart 고정), 폰 프레임은 390. 스레드 안의 답변·한도·끊김 상태는 캡처가 아니라 코드와 위젯 테스트(ask_history_test.dart)에서 유도한 시안이다(운영에서 질문을 보내지 않음).
