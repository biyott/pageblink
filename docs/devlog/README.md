# 🧪 개발 기록 (Devlog)

PageBlink 개발 과정을 **작업 단위별로 번호를 붙여** 남깁니다. 기획·설계 문서는 상위 [`docs/`](../), 결정 근거는 [`docs/adr/`](../adr/)에 둡니다.

## 파일 규칙

| 항목 | 규칙 |
|---|---|
| 파일명 | `NNN-kebab-주제.md` · 3자리 일련번호, 빈 번호 없이 증가 (예: `001-env-setup.md`) |
| 단위 | 게이트 1개, 기능 1개, 또는 문제 해결 1건 = 파일 1개 |
| 수행 일시 | 파일명이 아니라 **본문 헤더 표**에 KST로 기록: `시작` · `완료` · `최종 수정`. 값은 추측하지 않고 `TZ=Asia/Seoul date "+%Y-%m-%d %H:%M"`으로 얻음 |
| 작업 로그 | 단계마다 `HH:MM` 타임스탬프 한 줄씩 추가 (진행 중에도 계속 갱신) |
| 수정 | 기록을 고칠 때마다 `최종 수정` 일시를 갱신하고 **변경 이력**에 한 줄 추가. 내용이 뒤집히는 정정은 새 번호 기록으로 |
